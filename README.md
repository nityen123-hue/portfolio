# Abdullah Tariq — Developer Portfolio

A modern, responsive personal portfolio website built with **React.js**, **Bootstrap**, and **React Icons**.

The portfolio showcases my skills, services, projects, achievements, testimonials, FAQs, and contact information in a clean dark-themed interface.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile
* Sticky navigation bar
* Hero section with developer introduction
* About Me section
* Skills & Services section
* Featured Projects section
* Achievements timeline
* Client testimonial section
* Frequently Asked Questions (FAQ)
* Contact section
* Social media links
* Download CV button
* Bootstrap responsive grid
* React Icons integration
* Smooth section navigation using anchor links

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/abdullah-tariq-portfolio.git
```

Open the project folder:

```bash
cd abdullah-tariq-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

## 🏗️ Build for Production

Create a production build using:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
